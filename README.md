## 🚀 Comment Utiliser

### Ouvrir le site
1. Double-cliquez sur `index.html`
2. Le site s'ouvrira dans votre navigateur par défaut

### Personnalisation

#### Modifier les textes
- Ouvrez `index.html` avec un éditeur de texte
- Modifiez les textes directement dans le HTML

#### Changer les couleurs
- Ouvrez `styles.css`
- Modifiez les variables CSS au début du fichier :
```css
:root {
    --primary-color: #8B7355;    /* Couleur principale */
    --secondary-color: #D4A574;  /* Couleur secondaire */
    --accent-color: #9DB4A8;     /* Couleur d'accent */
    /* ... */
}
```

#### Ajouter des produits
- Copiez un bloc `.product-card` dans `index.html`
- Modifiez le titre, description, prix et image
- Ajoutez vos nouvelles images dans le dossier `Images/`

#### Configurer WhatsApp
- Dans `index.html`, trouvez le lien WhatsApp :
```html
<a href="https://wa.me/212XXXXXXXXX" class="whatsapp-float">
```
- Remplacez `212XXXXXXXXX` par votre numéro de téléphone au format international

## 🎯 Optimisations Recommandées

### Pour le lancement
1. **Domaine** : Enregistrez `naymahome.ma`
2. **Hébergement** : Utilisez un service comme :
   - Vercel (gratuit, facile)
   - Netlify (gratuit, facile)
   - Hostinger Maroc (payant, local)

3. **Images** : 
   - Optimisez vos images (compressez-les)
   - Format recommandé : JPEG ou WebP
   - Taille recommandée : max 500KB par image

4. **SEO** :
   - Ajoutez des meta descriptions
   - Optimisez les titres
   - Créez un sitemap

### Pour les ventes
1. **Pixel Facebook** : Ajoutez le pixel pour tracker les conversions
2. **Google Analytics** : Suivez vos visiteurs
3. **Formulaire de commande** : Intégrez un formulaire ou connectez à WhatsApp Business
